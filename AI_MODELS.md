## 1. TFLite MobileNetV2 (On-Device) ⭐

Model: `assets/models/mobilenetv2.tflite` (4.5 MB)  
Labels: `assets/models/labels.txt` (7 classes)  
Generated by: `ml_backend/` (Elixir Nx/Axon)

### Architecture
```
Input (224×224×3) → Normalize → MobileNetV2 backbone (1280-dim)
→ Dropout(0.3) → Dense(64) → Sigmoid(7 acne types)
```

### Output Classes
| Index | Class | Description |
|-------|-------|-------------|
| 0 | normal | Clear skin |
| 1 | whitehead | Closed comedones |
| 2 | blackhead | Open comedones |
| 3 | papule | Inflamed bumps |
| 4 | pustule | Pus-filled bumps |
| 5 | nodule | Deep hard lumps |
| 6 | cyst | Deep pus-filled lesions |

### Retrain (Elixir)
```bash
cd ml_backend
mix run ../scripts/generate_tflite_model.exs
```
Requires EXLA (Linux/macOS — not available on Windows).

## 2. Google Gemini API (Cloud)

Model: Gemini 2.0 Flash (multimodal)  
Key: `EXPO_PUBLIC_GEMINI_API_KEY` in `.env`

### كيف يعمل
Image → base64 → Gemini API → JSON `{issues, skin_type, severity}` → app

Gemini يطلب منه يرجع JSON منظم: أنواع الحبوب، الثقة، نوع البشرة، severity.

## 4. Elixir Nx Backend

### Architecture
```
Camera → image → Elixir API (port 4000) → Nx/Axon model → JSON → app
```

### Files (100% Elixir, ml_backend/)
| File | Purpose |
|------|---------|
| `lib/ml_backend/model.ex` | MobileNetV2 architecture (Nx/Axon) |
| `lib/ml_backend/preprocessing.ex` | Load image → resize 224 → normalize |
| `lib/ml_backend/inference.ex` | Run inference |
| `lib/ml_backend/acne_detection.ex` | Classify 6 acne types |
| `lib/ml_backend/severity.ex` | mild / moderate / severe |
| `lib/ml_backend/training.ex` | Training loop |
| `lib/ml_backend/convert.ex` | Export → ONNX / TFLite |
| `lib/ml_backend/api.ex` | HTTP API (Plug + Cowboy, port 4000) |

### Start
```bash
cd ml_backend && mix run --no-halt
```
Needs EXLA (Linux GPU recommended for training).
